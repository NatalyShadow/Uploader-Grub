# 🌱 Changelog — 1.5

> 🐛 The 1.5 releases of the little grub, flower by flower.
>
> 🌿 This changelog is built from the Git history and the version that was
> present in `package.json` at each commit. It only records what can be
> verified — no invented entries, no retroactive tags. 🌷

---

## [1.5.3] 🐞 — 2026-08-07

### 🐞 Fixed

- Quarantine failed files in the normal pipeline to stop infinite retries: files
  that cannot be processed are now moved to `_failed/` instead of being retried
  on every run.

---

## [1.5.1] 🌷 — 2026-08-07

### ✨ Added

- Per-folder file progress counter `[i/total]` in both the upload pipeline and
  the heavy processing mode (inline with `--process-heavy`).

### 🌿 Changed

- Heavy processing stays quality-first: `fast` preset with a `duration-scaled`
  ffmpeg timeout (no more arbitrary caps that could kill long encodes).

### ✨ Added

- Sized files that now fit the upload limit after heavy processing are promoted
  directly into their matching `images/` / `videos/` folders.

### 🐞 Fixed

- Route files over the size limit that are found in watcher folders to `heavy/`.

---

## [1.5.0] 🌻 — 2026-08-07

### ✨ Added

- Quality-first video watermarking: CRF encode + lossless audio copy
  (`-c:a copy`), meaning visual quality stays constant and audio is never
  re-encoded unless the container can't keep the original codec.
- Oversized files are still watermarked and remain in `heavy/` as marked copies,
  ready for manual upload.

---

  `package.json` version and is therefore not listed above — the commits
