# 🌱 Changelog — 1.3

> 🐛 The 1.3 releases of the little grub, flower by flower.
>
> 🌿 This changelog is built from the Git history and the version that was
> present in `package.json` at each commit. It only records what can be
> verified — no invented entries, no retroactive tags. 🌷

---

## [1.3.3] 🌼 — 2026-07-20

### 🐞 Fixed

- `MEDIA_NAME_PREFIX` is now normalised so the resulting name and UUID are
  always guaranteed separated by a single underscore (no run-on names like
  `prefixuuid`).

---

## [1.3.2] 🐞 — 2026-07-20

### 🐞 Fixed

- Oversized files found after watermarking are sent to `heavy/` instead of
  lingering around as originals.

---

## [1.3.1] 🐛 — 2026-07-20

### 🐞 Fixed

- Discord send retries improved (respect the rate-limit `Retry-After` on 429s).
- Watcher race condition fixed when the pipeline was still running while new
  events arrived.

---

## [1.3.0] 🌸 — 2026-07-18

### ✨ Added

- Files are namespaced with pluggable prefix via the `MEDIA_NAME_PREFIX`
  environment variable (organizer keeps `prefix_uuid.ext` clean).

### 🌿 Changed

- Added `@eslint/js` as a direct dependency for pnpm compatibility.
