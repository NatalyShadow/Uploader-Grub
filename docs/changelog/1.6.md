# 🌱 Changelog — 1.6

## [1.6.2] 🐞 — 2026-08-11

### 🐞 Fixed

- Stop leaking temporary `wm_*` files in `/tmp` when watermarking fails:
  `processFile` now unregisters and deletes its temp output before rethrowing
  the error, and `cleanupAllTemps()` runs before exit in the normal and
  `--process-heavy` modes as a backstop.

---

## [1.6.1] 🐛 — 2026-08-08

### 🌿 Changed

- Slimmed down the Docker runtime image so the container ships with
  production-only dependencies (Pruned `devDependencies` via `--ignore-scripts`
  after the build; the runtime stage no longer carries build tooling).

---

## [1.6.0] 🌼 — 2026-08-07

### 🌿 Changed

- Added several tooling quick wins:

    - Applied Prettier repo-wide and added a `verify` script.
    - Added `.editorconfig` so everyone writes the same way.
