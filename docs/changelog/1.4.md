# 🌱 Changelog — 1.4

> 🐛 The 1.4 releases of the little grub, flower by flower.
>
> 🌿 This changelog is built from the Git history and the version that was
> present in `package.json` at each commit. It only records what can be
> verified — no invented entries, no retroactive tags. 🌷

---

## [1.4.5] 🐝 — 2026-08-07

### 🌿 Changed

- Processed heavy files are moved back to the root level after processing instead
  of remaining nested.

### 🐞 Fixed

- Unprocessable heavy files are quarantined instead of being retried forever.

---

## [1.4.4] 🪱 — 2026-08-07

### ✨ Added

- New `--process-heavy` mode to watermark/compress the files waiting in
  `heavy/` folders without connecting to Discord.

---

## [1.4.3] 🐛 — 2026-07-20

### 🐞 Fixed

- Progress bar throttled to 5% steps, so it doesn't spam the output.
- Progress output now uses `stdout` (with `\r`) so it renders correctly even in
  non-TTY environments like Docker.

---

## [1.4.1] 🐞 — 2026-07-20

### 🐞 Fixed

- Show progress bar in non-TTY environments like Docker when viewing the
  container logs.

---

## [1.4.0] 🌻 — 2026-07-20

### ✨ Added

- Single-line progress bar during ffmpeg video processing, showing
  percent/elapsed time while the video is being watermarked.

---

## 🐞 Notes about this minor

- The intermediate number between `1.4.1` and `1.4.3` never carried its own
  `package.json` version and is therefore not listed above — the commit itself
  was released under the version stated in the previous header.
